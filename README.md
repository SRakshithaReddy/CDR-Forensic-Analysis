# CDR Forensic Analysis Dashboard

## Overview

A Python-based Call Detail Record (CDR) forensic analysis system developed for Digital Forensics and Information Security (DFIS).

The system analyzes call and SMS data to identify communication trends, suspicious activity, and telecom patterns using data visualization and an interactive Flask dashboard.

---

## Features

- Call Analysis
- SMS Analysis
- Suspicious Activity Detection
- Telecom Data Simulation
- Interactive Map Visualization
- Flask-based Dashboard

---

## Technologies Used

- Python
- Flask
- Pandas
- Matplotlib
- Folium
- HTML/CSS

---

## Project Files

- `cdr_script.py`
- `UI_script.py`
- `web_page.html`
- `map.html`
- `CDR_Report.pdf`

---

## How To Run

Install required libraries:

```bash
pip install pandas matplotlib flask folium
```

Run:

```bash
python cdr_script.py
python UI_script.py
```

Open browser:

```bash
http://127.0.0.1:5000
```
